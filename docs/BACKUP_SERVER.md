# เครื่องเซิร์ฟเวอร์สำรอง Smart Tha Pho

## เปิดใช้งาน

ดับเบิลคลิก **Smart Tha Pho Backup Server.exe** บนเดสก์ท็อป โปรแกรมจะตรวจ MySQL เปิด API พอร์ต 4200 เปิด Cloudflare Tunnel และส่งที่อยู่ API ใหม่ขึ้น repository สำรองโดยอัตโนมัติ ไม่ต้องเปิด XAMPP Control Panel เอง

- ลิงก์ภายในเครื่อง: http://127.0.0.1:4200/
- ลิงก์สำรอง: https://0tyght.github.io/smart-tha-pho-backup/
- ลิงก์ตรงออนไลน์: ดูจากหน้าตัวเปิดเซิร์ฟเวอร์ ใช้ได้ทันทีหลังสถานะออนไลน์พร้อม
- GitHub Pages อาจใช้เวลาสร้างหน้าเว็บใหม่หลังเปลี่ยนลิงก์ API ให้ใช้ลิงก์ตรงระหว่างรอ

ต้องเปิดเครื่อง เชื่อมอินเทอร์เน็ต และไม่ให้เครื่อง Sleep ขณะให้บริการ ปุ่มหยุดระบบจะหยุดเฉพาะ API และ Tunnel ที่ตัวเปิดนี้สร้าง ไม่ปิด MySQL ที่ใช้ร่วมกับโปรแกรมอื่น

## ข้อมูลและความเป็นส่วนตัว

ข้อมูลเริ่มต้นคัดลอกจากฐานข้อมูลในเครื่องนี้ตามที่เจ้าของงานเลือก ไม่ใช่ข้อมูลล่าสุดจากเครื่องหลัก และไม่มีการซิงก์ฐานข้อมูลระหว่างเครื่องอัตโนมัติ ข้อมูลที่แก้บนเครื่องสำรองอยู่เฉพาะฐานข้อมูล `smart_tha_pho_backup` ไม่เปลี่ยน `prms_tsm` เดิม

ไฟล์ SQL สำรองและรายงานตรวจจำนวนแถวอยู่ใน `.runtime/backups/` และ `.runtime/data-import.json` ซึ่งไม่ขึ้น GitHub เช่นเดียวกับ `.env`, บัญชีฐานข้อมูล และไฟล์อัปโหลด เก็บไฟล์เหล่านี้ในที่ปลอดภัย

## LINE และการสลับเครื่อง

ตัวสำรองนี้เปิดเว็บทั้งสี่ระบบ แต่ปิดงานตั้งเวลา การส่งข้อความออก และการเรียก LINE API เพื่อไม่ให้ส่งซ้ำกับเครื่องหลัก ไม่มีการเปลี่ยน Webhook หรือ Rich Menu ของเครื่องหลัก หากต้องการย้ายการทำงาน LINE มายังเครื่องสำรอง ต้องทำขั้นตอนสลับระบบโดยผู้ดูแลต่างหาก

## โครงสร้างตัวรัน

| ไฟล์ | หน้าที่ |
| --- | --- |
| `scripts/backup/BackupServerMonitor.cs` | หน้าจอ Windows และปุ่มควบคุม |
| `scripts/backup/server-control.ps1` | ลำดับเริ่ม/หยุด ตรวจสุขภาพ เปิด Tunnel อัปเดต Git |
| `scripts/backup/backup-api.mjs` | API แบบสำรอง ไม่เปิด scheduler และบล็อก LINE API |
| `scripts/backup/assemble-site.mjs` | รวมเว็บทั้งห้าส่วนสำหรับเสิร์ฟจากเครื่องเดียว |
| `scripts/backup/build-monitor.ps1` | สร้างไฟล์ `.exe` จากต้นฉบับ |

ค่าเฉพาะเครื่องอยู่ใน `.runtime/backup/machine.json` และ `.env` เท่านั้น บันทึกการทำงานอยู่ใน `.runtime/backup/` การติดตั้งครั้งนี้ใช้ MySQL ของ XAMPP, Node.js และ Git ที่มีอยู่ในเครื่อง โดยบันทึก path จริงใน `machine.json`

## สร้างหน้าเว็บใหม่เมื่อแก้โค้ด

```powershell
$env:SMART_THA_PHO_PUBLIC_SITE='1'
npm.cmd run build
node scripts/backup/assemble-site.mjs
powershell -ExecutionPolicy Bypass -File scripts/backup/build-monitor.ps1
```

กดหยุดและเริ่มจากตัวเปิดอีกครั้งเพื่อใช้โค้ดใหม่ ตัวเปิดไม่ pull โค้ด ไม่รัน migration และไม่เขียนทับฐานข้อมูลอัตโนมัติ

## แก้ปัญหา

- พอร์ต 4200 ถูกใช้: ตรวจโปรแกรมที่ใช้พอร์ต ตัวเปิดจะไม่ฆ่าโปรแกรมอื่น
- ฐานข้อมูลไม่พร้อม: ตรวจ `api-error.log` และ MySQL โดยไม่ลบโฟลเดอร์ข้อมูล
- Git push ไม่ผ่าน: ใช้ลิงก์ตรงจากตัวเปิดก่อน แล้วตรวจ GitHub login และสิทธิ์ repository สำรอง
- Tunnel ไม่พร้อม: ตรวจอินเทอร์เน็ตและ `tunnel.log` โปรแกรมใช้ HTTP/2 เพื่อลดปัญหา QUIC ของเครือข่ายเดิม
- ต้องย้ายโปรเจกต์: ตั้ง environment variable `SMART_THA_PHO_BACKUP_ROOT` ให้ตรงกับโฟลเดอร์ใหม่และปรับค่าเฉพาะเครื่อง

Cloudflare Quick Tunnel เป็น URL ชั่วคราวสำหรับทดสอบ/พัฒนา ไม่มี SLA และเปลี่ยนเมื่อเริ่มใหม่ ลิงก์ GitHub Pages คงเดิมแต่ระบบจะอัปเดตที่อยู่ API ให้ หากต้องการใช้งานจริงต่อเนื่องควรตั้ง Named Tunnel และโดเมนถาวร: https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/
