# Backup monitor surface

Mode: Operate. Scope: only the native Windows backup-server launcher, not the web applications.

## Direction contract

THESIS: A simple native Windows status window, explicitly approved by the owner; no invented dashboard or decorative theme.

OWN-WORLD: Standard Windows controls, white system surface, Tahoma 10-point text, 17-point title, green ready text and dark-red errors with written state labels. No icons or generated artwork.

STORY: Opening starts the sequence; the owner sees database, API and online readiness, then opens or copies the direct URL. Failure preserves the local-service link and exposes the log folder.

FIRST VIEWPORT: Title and current action at top, three aligned service-status rows, read-only direct URL, four action buttons, local/Pages/log links, and a short LINE/data note at bottom. Resizable native window with DPI scaling.

FORM: Precisely specified native form approved in chat; no open-ended direction round. seed: none (user-pinned native form; concept roll not required).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
