# Product

<!-- impeccable:product-schema 1 -->

## Platform

Windows desktop utility (WinForms), supporting the existing web platform.

## Users

The project owner starts a backup server on this Windows machine without running individual commands.

## Product Purpose

Double-click an executable on Desktop, see database/API/online readiness, open the backup website, and stop or restart the backup processes.

## Operating Context

The owner confirmed a simple native Windows interface. Start automatically when opened. Show real health, errors, and the online URL. Use the current local dataset in a separate database. Keep the primary deployment untouched.

## Capabilities and Constraints

Public code repository is `0tyght/smart-tha-pho-backup`. Real SQL, uploads, passwords, and machine-specific files remain local. No automatic data synchronization or primary LINE takeover. Native Windows controls and code-first implementation are part of the confirmed brief.
